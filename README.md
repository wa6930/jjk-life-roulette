# 咒术回战·人生轮盘

> 转动命运之轮，书写你的咒术人生。

一款基于《咒术回战》世界观的互动式人生模拟 PWA 应用。通过轮盘随机决定出身、术式与命运事件，体验从转生到传说的完整咒术师人生。

## 游戏特色

- **轮盘驱动**：出身、术式、事件均由轮盘随机决定，每局体验不同
- **完整人生线**：转生 → 幼年 → 高专 → 实战 → 传说 → 结局，六大阶段
- **丰富设定**：多种出身（咒术师名门、容器体质、半咒灵混血…）、术式体系、阵营选择
- **角色互动**：与原作角色建立关系，好感度影响剧情走向
- **多结局**：根据属性、标签、选择触发不同结局评价
- **PWA 离线可用**：支持添加到主屏幕，无需网络即可游玩

## 技术栈

| 技术 | 版本 |
|------|------|
| React | 18.3 |
| TypeScript | 5.6 |
| Vite | 6.0 |
| PWA (vite-plugin-pwa) | 0.21 |

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建产物
npm run preview
```

## 项目结构

```
src/
├── data/           # 游戏数据（角色、出身、术式、事件、结局）
├── game/           # 游戏引擎（状态机、轮盘逻辑）
├── hooks/          # React Hooks
├── utils/          # 工具函数（存档、导出）
└── types.ts        # 核心类型定义
```
